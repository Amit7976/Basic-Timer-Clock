# ⏱️ Basic Timer Clock

A simple, minimal, and functional **Timer Clock** built using pure **HTML**, **CSS**, and **JavaScript**.  
Ideal for practice, productivity tools, or just learning how to manage time in the browser!

🌐 **Live Demo**: [Try the Timer Clock](https://amit7976.github.io/Basic-Timer-Clock/)

---

## ✨ Features

- ⏳ Start, Stop, and Reset timer functionality  
- 🔄 Realtime countdown/up updates  
- 📱 Clean and responsive UI  
- 🧠 Great beginner project for mastering `setInterval()` in JavaScript

---

## 🛠️ Tech Stack

- HTML5  
- CSS3  
- JavaScript (Vanilla)
